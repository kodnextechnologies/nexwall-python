# GitHub repository metadata

## About (description)

Tiny Python client and CLI for the free NexWall Wallpaper API: list categories, search wallpapers, get a random wallpaper, download it, and change your desktop wallpaper daily on Windows, macOS and Linux. One dependency (requests), handles rate limits (429). MIT licensed.
